# Модуль оплаты ХуткiГрош (ЕРИП) для CS-Cart

Модуль обеспечивает взаимодействие интернет-магазина на базе **CS-Cart** с платёжным сервисом [ХуткiГрош](https://hutkigrosh.by): выставление счетов в ЕРИП (АИС "Расчет"), оплата картой (WebPay), QR-код, автоматическое обновление статусов заказов после оплаты.

## Поддерживаемые версии

Поддерживаются одновременно две версии модуля:

| | [HutkiGrosh API v3](#настройка-hutkigrosh-api-v3) (рекомендуется) | [HutkiGrosh](#настройка-hutkigrosh-предыдущее-поколение) (предыдущее поколение) |
|---|---|---|
| Текущая версия | 4.0.8 (`cs-cart-hutkigrosh-module-apiv3.zip`) | 3.0.0 (`cs-cart-hutkigrosh-module.zip`) |
| API | актуальное поколение (REST API v3) | предыдущее поколение API |
| Подключение | API-токен, выбор услуги из списка | логин/пароль, ЕРИП ID вручную |
| Тестовая система | api-sandbox.hgrosh.by | trial.hgrosh.by |
| Кому подходит | новым магазинам и тем, кто переходит на API v3 | действующим магазинам, работает как раньше |

> Сервис ХуткiГрош сейчас поддерживает все поколения API параллельно.

Следите за анонсами о сроках отключения старого API и переходите на API v3 заранее (порядок перехода описан в разделе "[Одновременная работа и переход на API v3](#одновременная-работа-и-переход-на-api-v3)").

## Скачать

Для каждой версии CS-Cart используется свой файл сборки (.zip):

| CS-Cart | Сборка API v3 (рекомендуется) | Сборка предыдущего поколения |
|---|---|---|
| 4.x | [cs-cart-hutkigrosh-module-apiv3.zip](https://github.com/esasby/cmsgate-cscart-hutkigrosh/blob/master/cs-cart-hutkigrosh-module-apiv3.zip) (проверено на 4.20.1) | [cs-cart-hutkigrosh-module.zip](https://github.com/esasby/cmsgate-cscart-hutkigrosh/blob/master/cs-cart-hutkigrosh-module.zip) (проверено на 4.7, 4.11) |

Отдельная сборка API v3 обусловлена сменой поколения API сервиса, а не изменениями CS-Cart: внутри одной версии CMS обе сборки отличаются только поколением API.

## Требования

- PHP 5.6 и выше, расширение [cURL](https://www.php.net/manual/ru/book.curl.php)

## Установка (одинакова для обеих версий модуля)

**CS-Cart 4.x:**

1. Создайте резервную копию магазина и базы данных.
1. Скачайте архив нужной сборки (раздел "Скачать").
1. В административной части CS-Cart выберите `Модули > Управление модулями > Загрузить и установить модуль`, выберите архив и нажмите "Загрузить и установить".
1. Перейдите в меню `Администрирование > Способы оплаты`. В списке появятся два новых способа оплаты (создаются инсталлятором автоматически):
   * **Через систему «Расчет» (ЕРИП)** - содержит основные настройки модуля;
   * **Оплата картой** - использует общие настройки с первым способом и перенаправляет клиента к оплате счёта картой (WebPay).
1. Перейдите к редактированию способа оплаты "Через систему «Расчет» (ЕРИП)" и заполните параметры (см. разделы настройки ниже).

## Настройка HutkiGrosh API v3

### Шаг 1. Получите API-токен

В бизнес-аккаунте ХуткiГрош откройте **Настройки > Интеграция ПУ** (раздел доступен ролям "Владелец ПУ" и "Администратор ПУ"). Используйте токен с доступом к информации о ПУ и созданию/редактированию счетов.

### Шаг 2. Подключите магазин

1. В настройках модуля вставьте токен в поле **API Токен**.
1. Нажмите кнопку "Актуализировать" (рядом с полем **API Токен**), модуль загрузит из ХуткiГрош справочники для полей **Услуга**, **Розничная торговая точка**, **Кассовое место** (загруженные значения сохраняются в настройках и восстанавливаются при открытии формы без обращения к API).
1. Выберите значения в списках и сохраните изменения.

### Шаг 3. Остальные параметры

**Основное:**
* **Sandbox**: тестовый режим работы, счета выставляются в тестовую систему `api-sandbox.hgrosh.by` с токеном тестовой системы.
* **Debug mode**: отображение деталей ошибок.
* **Путь в дереве ЕРИП**: путь, по которому клиент будет искать выставленный счёт (например, `АИС "Расчет" (ЕРИП) > Интернет-магазины/сервисы >`).
* **Срок действия счета (дней)**: как долго счёт будет доступен в ЕРИП для оплаты (от 1 до 10).

**Экран успешного заказа:**
* **Секция "Инструкция"**: пошаговая инструкция по оплате счёта в ЕРИП.
* **Секция QR-код**: оплата счёта по QR-коду через мобильное приложение банка (QR-код и ссылка на оплату запрашиваются у сервиса).
* **Секция Webpay**: кнопка оплаты счёта картой (переход на Webpay).
* **Текст успешного выставления счета**: может содержать HTML, допустимы переменные `@order_id`, `@order_number`, `@order_total`, `@order_currency`, `@order_fullname`, `@order_phone`, `@order_address`.
* **CSS файл для итогового экрана**: путь к собственному CSS-файлу оформления.

**Статусы заказов** (выбор из существующих статусов магазина, список статусов - `Администрирование > Статусы заказов`):
* **Статус при выставлении счета**: какой статус установить заказу после выставления счёта в ЕРИП. Рекомендуется "Открыт" (O), заказ ожидает оплаты.
* **Статус при успешной оплате счета**. Рекомендуется "Выполнен" (C), оплата получена, заказ ожидает комплектации и отправки.
* **Статус при отмене оплаты счета**. Рекомендуется "Отменен" (N).
* **Статус при ошибке оплаты счета**. Рекомендуется "Неудавшийся" (F).

**Уведомления** (отправляются шлюзом ХуткiГрош):
* **Email оповещение**: письмо клиенту при успешном выставлении счёта.
* **Sms оповещение**: SMS клиенту при успешном выставлении счёта.

**Способы оплаты для клиента:**
* Названия и описания способов оплаты задаются стандартными полями CS-Cart при редактировании способа оплаты (по умолчанию "Через систему «Расчет» (ЕРИП)" и "Оплата картой").

### Обязательно: адрес обработчика уведомлений

Для автоматического обновления статуса заказа (после оплаты клиентом счёта в ЕРИП) сообщите в службу технической поддержки ХуткiГрош адрес обработчика, указав Ваш домен:

```
https://ваш-домен/index.php?dispatch=hutkigrosh.notify
```

Модуль принимает уведомление GET-запросом с идентификатором счёта (`purchaseid`) в URL.

### Тестовый режим (Sandbox)

1. Получите API-токен тестовой системы (выдаётся при регистрации в ХуткiГрош).
1. Включите в настройках модуля режим **Sandbox** и настройте согласно инструкции выше.
1. Счета будут выставляться в тестовую систему `api-sandbox.hgrosh.by`.
1. Для эмуляции оплаты счёта используйте [личный кабинет](https://cabinet.hgrosh.by) (сверху-справа "Профиль пользователя" > "Тестовый режим").

Документация API v3: https://api-dev.hgrosh.by/eripservice/docs/ru/index.html

**Параметры подключения:**
* **Логин**: Ваш логин для доступа к ХуткiГрош.

* **ЕРИП ID**: уникальный идентификатор услуги в ЕРИП.
* **Код услуги**: код услуги в дереве ЕРИП, используется при генерации QR-кода.
* **Sandbox**: тестовый режим, счета выставляются в тестовую систему `trial.hgrosh.by`.

**Основное:**
* **Debug mode**: отображение деталей ошибок.

* Используйте данные для подключения к тестовой системе, полученные при регистрации в ХуткiГрош.

* Для эмуляции оплаты клиентом выставленного счёта воспользуйтесь [личным кабинетом тестовой системы](https://trial.hgrosh.by) (меню "Тест оплаты ЕРИП").

## Одновременная работа и переход на API v3

* Обе сборки являются одним и тем же расширением (модуль `hutkigrosh`, общие способы оплаты и общая группа настроек): сборка API v3 устанавливается **поверх** предыдущей версии и замещает её файлы; заказы и данные магазина не затрагиваются. Обратный переход выполняется установкой предыдущей сборки поверх.
* Адрес обработчика уведомлений **не меняется**: сообщать в поддержку ХуткiГрош новый адрес не нужно.
* Способы оплаты в магазине остаются прежними ("Через систему «Расчет» (ЕРИП)" и "Оплата картой"): двойная обработка уведомлений исключена.
* Настройки статусов, текстов и секций сохраняются при переходе; поля подключения меняются: вместо "Логин/Пароль/ЕРИП ID/Код услуги" заполняется "API Токен" и справочники "Услуга", "Розничная торговая точка", "Кассовое место" (ранее сохраненные значения остаются в базе данных).

Рекомендуемый порядок перехода:

1. Создайте резервную копию магазина и базы данных.
1. Получите API-токен тестовой системы (см. "Настройка HutkiGrosh API v3", шаг 1).
1. Установите сборку API v3 поверх предыдущей версии (порядок установки см. в разделе "Установка").
1. В настройках модуля вставьте токен в поле "API Токен", нажмите "Актуализировать" и выберите значения в списках "Услуга", "Розничная торговая точка", "Кассовое место".
1. Включите режим Sandbox и проверьте выставление и оплату счёта (эмуляция оплаты в личном кабинете тестовой системы, см. "Тестовый режим").
1. Выключите Sandbox и вставьте токен, выданный для рабочей системы, в поле "API Токен", нажмите "Актуализировать" и выберите значения в списках "Услуга", "Розничная торговая точка", "Кассовое место": счета будут выставляться в рабочую систему `api.hgrosh.by`.
1. Проверьте обработчик уведомлений: статус заказа в магазине должен измениться после оплаты счёта.

## Логи

Модуль ведет лог файл по пути (для обоих поколений API одинаковому):

* `<корень_сайта>/app/addons/hutkigrosh/lib/vendor/esas/cmsgate-core/logs/cmsgate.log`

Для обеспечения **безопасности** необходимо убедиться, что в настройках http-сервера включена директива `AllowOverride All` для корневой папки.
